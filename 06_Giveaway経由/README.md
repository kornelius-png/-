# Giveaway経由

**対象**：Giveaway（プレゼント企画）施策経由のリード。参加者の回答で2つの目的に分けて追う：①営業＝回答者の勤務先から求人（案件）を獲得できるか、②仕入れ＝回答者の転職を支援できるか。**Giveaway告知のためのMeta広告経由の参加者もここに計上**し、インスタ広告（01）には含めない
**中心の問い**：Giveaway経由を通じて、国内採用を最大化するにはどうすればよいか？

## フォルダ構成
| フォルダ | 内容 |
|---|---|
| 01_データ | 生データ・エクスポート（CSV、広告レポート等） |
| 02_分析 | 集計・ファネル分析・考察 |
| 03_施策 | 打ち手の案・実施記録・結果 |

## 追うべき指標（案）
- キャンペーン別参加数
- 新規フォロワー/LINE登録数
- リードの質（応募意向あり率）
- 応募数
- 採用数
- 施策コスト・CPA

## 検証したい論点（案）
- [ ] 景品設計と質の関係
- [ ] 参加条件の設計（LINE登録など）
- [ ] 企画後のナーチャリング導線
